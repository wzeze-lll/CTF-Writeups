# neuron_shuffle — 一页结论（可直接提交给主办方）

## 文件
- `check.py`：`canon = 三组逗号分隔整数（分号分组）`；`body=sha256(canon)[:32]`；`V=sha256("ns::"+body)`
- `model_A.npz`：8 个 float64 数组（44982 B，zip 未压缩）
- `model_B.bin`：44982 B，熵 7.9966

## 可确定的结构（已复现）
- 网络 `16 → 32 → 40 → 48 → 32`；权重 `k1(16,32) k6(32,40) k2(40,48) k5(48,32)`；bias `k0/k7/k4/k3`
- 基矩阵尺寸 `16×10 / 10×11 / 12×13 / 14×32`（不同取值数 160/110/156/448 精确等于乘积）
- 926 个独立抽样：8 个数组去重值集合**两两不相交**，并集恰为 926
- 每层神经元 `(入边列类, 出边行类, bias类)` 三层分别 **32/32、40/40、48/48 全唯一**
  （独立随机下概率 0.83%×0.10%×0.08% ≈ **6.6×10⁻⁹** ⇒ 刻意构造的网格）

## 不可确定的部分
- 三元组的**编号顺序**不在任何文件里：等价类 10!³·12!·11!·12!·14!·13!·14! = **2.07×10⁷⁶ ≈ 254 bit**
  （若“任意置换都算合法”则 32!·40!·48! ≈ 480 bit）
- 而 `check.py` 只提供 **128 bit** 校验 ⇒ 候选/flag 空间比 **7.8×10¹⁰⁵**

## model_B.bin 无法承担“原序”作用

位打包(5~8bit)/字节 mod n/uint16/uint32 置换全 0｜keystream 构造全 0｜36 个数组派生密钥 × AES/RC4/ChaCha 全 0
