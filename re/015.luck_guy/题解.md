# GXYCTF 2019 luck_guy：分支拼接与奇偶减法

程序不是把完整 flag 明文连续存放。先看控制流中各分支给字符串数组写入的字符，按实际执行顺序拼出固定前缀；随后对另一段字节按下标奇偶减去 `1` 或 `2`。

本地 ELF 的静态检查能找到前缀 `GXY{do_not_` 和编码字节 `69 63 75 67 60 6f 66 7f`。逐字节逆算：偶数下标减 1，奇数下标减 2，得到 `hate_me}`。合并为：

```text
GXY{do_not_hate_me}
```

周记把平台答案记作 `flag{do_not_hate_me}`，但本地附件常量与程序构造出的题目字符串使用 `GXY{...}`。提交时应按题目平台实际要求处理外壳；正文是 `do_not_hate_me`。

脚本：[solve1.py](solve1.py)。脚本会在 ELF 中核对前缀和编码字节，再执行奇偶逆变换；这证明静态数据与运算吻合，不代表已运行原程序提交验证。
