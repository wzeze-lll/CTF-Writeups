## 变换链

程序对输入做了三步处理，再与内置字符串比较：

```text
输入 → 自定义 Base64 编码 → 大小写互换 → 比较
```

自定义 Base64 表由标准表 `ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/` 生成：把下标 `6..14` 的字符分别与下标 `16..24` 的字符交换。目标字符串是 `zMXHz3TIgnxLxJhFAdtZn2fFk3lYCrtPC2l9`。

逆向时顺序相反：先把目标串大小写互换，再将自定义表字符映射回标准 Base64 表，最后 Base64 解码。解出的 flag：

```text
flag{bAse64_h2s_a_Surprise}
```

## 求解脚本

```python
import base64

standard = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/'
custom = list(standard)
for i in range(6, 15):
    custom[i], custom[i + 10] = custom[i + 10], custom[i]
custom = ''.join(custom)

cipher = 'zMXHz3TIgnxLxJhFAdtZn2fFk3lYCrtPC2l9'
stage1 = cipher.swapcase()
base64_text = ''.join(standard[custom.index(ch)] for ch in stage1)
print(base64.b64decode(base64_text).decode('ascii'))
```
