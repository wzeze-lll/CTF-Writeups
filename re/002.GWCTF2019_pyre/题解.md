# GWCTF 2019 pyre：逆转按位异或与索引加法

附件是 Python 字节码。周记中的两种反编译工具截图说明，可以先恢复字节码结构，再顺着校验逻辑还原每一步；仓库保留 `.pyc`、反编译文件和求解脚本。

## 逆向过程

把关键变换写成两个阶段：

```text
明文 → 每个字节加下标（模 128） → 与下一个字节异或 → 密文
```

相邻 XOR 从左向右覆盖了数组中的值，因此还原时要从倒数第二项向前处理：`a[i] ^= a[i+1]`。随后再对第 `i` 个字节减去 `i`（模 128），即可还原明文。不能从左向右做第一步，否则右侧仍是密文态，无法恢复正确前项。

```python
code = bytes([
    0x1f, 0x12, 0x1d, 0x28, 0x30, 0x34, 0x01, 0x06,
    0x14, 0x34, 0x2c, 0x1b, 0x55, 0x3f, 0x6f, 0x36,
    0x2a, 0x3a, 0x01, 0x44, 0x3b, 0x25, 0x13,
])
values = list(code)
for i in range(len(values) - 2, -1, -1):
    values[i] ^= values[i + 1]
plain = bytes((value - i) % 128 for i, value in enumerate(values))
print(plain.decode('ascii'))
```

周记记录的结果是 `flag{Just_Re_1s_Ha66y!}`。仓库的 [solve.py](solve.py) 还会按正向顺序重新加密，并断言结果与附件中的常量一致。

## 复盘

- 看到 `.pyc`，先确认 Python 版本，再用反编译工具恢复控制流；不要把伪代码输出直接当作原始源码。
- 逆运算顺序要反过来；对“左项依赖右项”的原地变换，倒序遍历常是关键。
- 正向回验用于确认脚本和常量一致，不等于把原始题目程序动态运行通关。
