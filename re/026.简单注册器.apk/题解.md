# 简单注册器：输入校验与 flag 生成是两条逻辑

这是 Android APK。JADX 反编译 `MainActivity` 后可以看到，按钮回调先检查输入注册码，再根据内置字符数组生成并显示 flag。注册码不等于 flag，且题目只检查注册码的长度和三个位置关系。

## 注册码检查

有效输入需满足：

```text
长度为 32
第 2 个字符（下标 1）为 b
最后一个字符（下标 31）为 a
第 1 个字符与第 3 个字符的 ASCII 值之和为 104
```

例如 `5b3` 后接 28 个 `0`，最后再接 `a`，满足这些反编译条件。输入它会进入成功分支；这只说明客户端校验通过。

## flag 的生成

程序以 `dd2940c04462b4dd7c450528835cca15` 初始化字符数组，修改下标 `2、4、30、14`，然后把整个 32 字符数组反转，最后加上 `flag{}` 外壳。可以按相同操作复现：

```python
x = list(map(ord, 'dd2940c04462b4dd7c450528835cca15'))
x[2] = x[2] + x[3] - 50
x[4] = x[2] + x[5] - 48
x[30] = x[31] + x[9] - 48
x[14] = x[27] + x[28] - 97
for i in range(16):
    x[i], x[31 - i] = x[31 - i], x[i]
print('flag{' + ''.join(map(chr, x)) + '}')
```

周记里记录的输出为 `flag{+59acc538825054c7de4b26440c0999dd+}`。仓库 `solve.py` 从本地 APK 的反编译逻辑复算输出；没有运行 APK 点击按钮，因此不把脚本结果称为设备动态验证。
