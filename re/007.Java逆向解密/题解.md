# Java逆向解密：反转逐字符异或

本地 `Reverse.class` 的 `Encrypt` 函数对每个字符执行：

```text
result = (character + 64) XOR 32
```

目标数组为：

```text
180, 136, 137, 147, 191, 137, 147, 191, 148,
136, 133, 191, 134, 140, 129, 135, 191, 65
```

异或自身可逆，所以先对每个目标值 XOR `32`，再减 `64`，还原输入字符：

```python
key = [180, 136, 137, 147, 191, 137, 147, 191, 148,
       136, 133, 191, 134, 140, 129, 135, 191, 65]
plain = bytes((value ^ 32) - 64 for value in key)
print(plain.decode('ascii'))
```

脚本还原出的输入正文是 `This_is_the_flag_!`；周记记录的提交格式是：

```text
flag{This_is_the_flag_!}
```

附件中也保留了 Java 反编译结果、C 版本和 Python 求解脚本。旧 `draft_incorrect.c` 的表达式 `key[i]^0x20-64` 按 C 运算优先级会被解析成 `key[i] ^ (0x20 - 64)`，而有符号 `char` 还会带来负值问题；请运行 `solve1.c` 或 `solve1.py`。脚本会按前向表达式回算目标数组，属于静态代数核验，不等于原 Java 程序动态通关。
