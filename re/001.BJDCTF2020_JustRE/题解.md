# BJDCTF2020 JustRE：补齐格式串中的两个整数

这题的 flag 模板直接保存在程序里，两个 `%d` 由输入推导。按附件中的格式串和校验条件，两个整数分别是 `19999` 与 `0`，代入得到：

```text
BJD{1999902069a45792d233ac}
```

## 逆向思路

1. 在 IDA 中从成功提示或 `printf` 格式串的交叉引用进入主逻辑。
2. 记录格式串：`BJD{%d%d2069a45792d233ac}`。
3. 沿输入与条件分支确认前两个十进制占位数的取值，再原样代入模板。不要把 `%d` 当作两个单字符占位：`19999` 本身占五位。
4. 用脚本检查附件中存在模板，再计算完整输出。

## 求解脚本

```python
from pathlib import Path

sample = next(Path(__file__).parent.glob('*.exe'))
assert b'BJD{%d%d2069a45792d233ac}' in sample.read_bytes()

answer = 'BJD{%d%d2069a45792d233ac}' % (19999, 0)
print(answer)
```
