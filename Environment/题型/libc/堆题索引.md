# 堆题索引

堆利用和 glibc 补丁版强相关（fastbin/unsorted bin/tcache 偏移、hook 符号都随版本变），所以堆题内部按 **glibc 版本 → 架构 → 题目** 分组，题目直接放在 [`libc/<版本>/<架构>/`](ORIGINAL_NOTES.md) 里，和运行库同目录；题目目录自带 `env/` 的优先用自己的。

| 题目 | 版本 / 架构 | 学习重点 | 状态 |
| --- | --- | --- | --- |
| [UAF / hacknote](../../../PWN/Heap/032.hacknote/ORIGINAL_NOTES.md) | 2.23 / i386 | UAF、fastbin、GOT 覆盖 | 本地兼容候选；EXP 未在 VM 跑通 |
| [wdb_2018_1st_babyheap](../../../PWN/Heap/031.wdb_2018_1st_babyheap/ORIGINAL_NOTES.md) | 2.23 / amd64 | double free、fastbin dup、`__malloc_hook` | 附件自带 `env/`；仅静态确认 |
| [ciscn_2019_es_1](../../../PWN/Heap/033.ciscn_2019_es_1) | 2.27 / amd64 | UAF、unsorted bin、tcache | 自带 libc/ld；本地启动过，EXP 未跑通 |
| [ciscn_2019_final_3](../../../PWN/Heap/034.ciscn_2019_final_3) | 2.27 / amd64 | tcache | 本地兼容候选 |
| [hitb2018_gundam](../../../PWN/Heap/035.hitb2018_gundam) | 2.27 / amd64 | tcache | 本地兼容候选 |
| [VIPhouse](../../../PWN/Heap/036.VIPhouse/ORIGINAL_NOTES.md) | 2.35 / amd64 | login/note 堆操作 + fmt/uaf/canary 菜单 | 本地兼容候选；仅静态确认 |

- `ciscn_2019_es_1` 目录里带着自己的 `libc.so.6`/`ld-2.27.so`，脚本用 `--library-path` 指向题目目录；其余题用 `libc/2.23/...` 或 `libc/2.27/amd64/glibc227/` 的运行库。
- `PicoCTF_2018_are_you_root` 也是 malloc 出来的 `user` 结构体被 UAF 复用，但原目录标的是 `2.27/i386`、二进制实际是 x86-64，版本/架构口径没核实，按用户确认先放 [`other/2.27/amd64/are_you_root/`](../../../PWN/Heap/037.are_you_root)。
- 版本标签：“附件匹配”指题目自带对应 libc/loader 且验证过；“本地兼容候选”只说明架构和符号需求允许，不代表远程环境版本。
